# Netflix UI Clone

A responsive front-end replica of the Netflix streaming interface built using semantic **HTML5**, **CSS3**, and **Vanilla JavaScript**.

## Features
- **Responsive Layout:** Adapts across desktop, tablet, and mobile viewports using CSS Flexbox and media queries.
- **Dynamic Catalog Rendering:** Populates categorized horizontal carousels dynamically from structured JavaScript data.
- **Live Search & Category Filtering:** Filter titles in real time by keyword or genre directly from the navigation bar.
- **Interactive Preview Modal:** Click any title card or hero CTA to inspect metadata, synopsis, and toggle "My List" state.

## Tech Stack
- HTML5
- CSS3 (Custom Properties, Flexbox, Responsive Design)
- JavaScript (ES6+ DOM Manipulation, Event Handling)
